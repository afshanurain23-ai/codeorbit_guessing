🎮 Number Guessing Game in Python

📌 Project Description

The Number Guessing Game is a simple, interactive Python project in which the computer randomly selects a number between 1 and 100, and the player tries to guess it.

The program provides hints such as "Too low!" or "Too high!" to help the player guess the correct number. Once the player guesses correctly, the program displays the correct number and the total number of attempts.

The player can also choose to play multiple rounds.

🎯 Objectives

- To understand the basics of Python programming.
- To generate random numbers using Python.
- To use loops and conditional statements.
- To handle invalid user inputs using exception handling.
- To create an interactive command-line game.

🛠️ Technologies Used

- Programming Language: Python
- Module: "random"
- Concepts: Loops, conditional statements, user input, and exception handling.

✨ Features

- Generates a random number between 1 and 100.
- Provides hints when the guess is too high or too low.
- Counts the number of valid attempts.
- Handles invalid inputs.
- Allows the player to play multiple rounds.
- Displays the correct number and total attempts when the player wins.

⚙️ How to Run the Project

Prerequisites

- Python 3 installed on your computer.
- A code editor such as VS Code or any Python IDE.

Steps

1. Clone or download this repository.
2. Open the project folder in your code editor.
3. Save the Python code in a file named "number_guessing_game.py".
4. Open the terminal in the project folder.
5. Run the following command:

python number_guessing_game.py

If your system uses the "python3" command, run:

python3 number_guessing_game.py

🎮 How to Play

1. Run the program.
2. The computer selects a random number between 1 and 100.
3. Enter your guess.
4. Follow the hints provided by the program.
5. Continue guessing until you find the correct number.
6. Check your total attempts.
7. Enter "yes" to play another round or "no" to exit the game.
